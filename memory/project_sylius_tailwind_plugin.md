Projet de conversion des templates Twig du SyliusShopBundle de Bootstrap vers Tailwind CSS + daisyUI.

**Chemins clés :**
- Source Sylius : `vendor/sylius/sylius/src/Sylius/Bundle/ShopBundle/templates`
- Thème converti : `themes/TailwindTheme/templates/bundles/SyliusShopBundle`
- Assets CSS : `themes/TailwindTheme/assets/css`
- Assets JS : `themes/TailwindTheme/assets/js`

**Suivi d'avancement :** `prompt.md` (tableau par dossier avec statuts)

**Why:** Plugin de thème Sylius 2.0 basé sur Tailwind CSS 4 + daisyUI, remplacement complet de Bootstrap.

**How to apply:** Toujours vérifier le tableau de `prompt.md` avant de commencer une session, travailler dossier par dossier.
